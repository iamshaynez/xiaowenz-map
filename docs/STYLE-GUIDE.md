# 样式指南

> 这份文件写的是"这座城是怎么画出来的"，改渲染的人先读它。规则来自 pixel-plays 的 README 和 `engine.js`，在城市版里落在 `app/src/gl/` 的几份着色器里。

## 一张色阶表管所有颜色

每个颜色是一个基色（`app/palette.json`），渲染时按原版的 `rampOf` 生成五级：暗部偏紫（冷色 [46, 38, 84]），亮部偏暖（暖色 [255, 232, 180]）。GPU 从一张 5 × N 的色阶纹理里取，不在单精度里重算。换季节就是重排这张纹理。

烘焙数据用"名字在列表里的序号"引用颜色，所以列表只能往后加，不能改序（D019）。

## 像素是先决条件

- 内部画面最多 960 × 540，桌面默认每个像素占 2 个 CSS 像素；手机上一个像素一个 CSS 像素（D037），画面宽度不少于 320 像素。
- 所有按像素的判定（抖动、噪声、溶解边缘、树冠的明暗）都在低分辨率像素**中心**做；超采样只决定一个像素有没有被盖到，取最近的被盖到的采样点（D012、D015）。
- 噪声的尺度是像素而不是米：`grainAt(world, 像素数, seed)` 把噪声频率除以缩放，所以拉近时它保持颗粒，不会变成一片平色或一层碎点。

## 光与影

- 光固定在**画面**的左上方，跟着相机转（D017）：顶面最亮，朝向左下的面居中，朝向右下的面最暗。旋转时楼的明暗随朝向连续变化，影子永远落向画面右下方。
- 面的亮度：`1.75 + 0.55·(朝向) + 1.65·(朝上的份额)`。墙是单位向量，平顶朝上份额为 1，坡面介于两者之间。
- 投影是从太阳视角画的阴影贴图（D016），1024 × 1024，每帧只画建筑、屋顶小件、树和车辆的深度。只有地面、水面、道路、桥面和树冠接影；墙和屋顶不接影，所以街道档的阴影只落在地面上，和原版一样。
- 影子的颜色是原版的紫灰：`floor(c · (0.54, 0.52, 0.72))`。看图的模型多次说大片阴影"发紫"，这是原版的样子，列在 `REVIEW-QUEUE.md` 里供你定夺。
- 环境光遮蔽：地面像素周围 2 和 4 像素处 16 个点里有 8 个以上被挡就压暗，1–7 个按抖动压暗；直接移植。

## 描边

`shadeEdges` 的移植：非地面的像素，挨着地面的那圈压暗到 0.68 倍；深度往上跳 2.8 个像素的是朝阳的边，混入暖色；往下跳的是背光的边，压到 0.74 倍。

## 四个缩放档怎么分工

| 档 | 1 像素 | 画什么 |
|---|---|---|
| 全景 | 0.125 像素/米以下 | 125 米的地形网格；50 米栅格的地面色，建成区按楼高着成有明暗的"台面"；主路、铁路、运河是永远不细于 1 像素的线；0.04 起画 50 米一格的体块 |
| 城区 | 0.125 起 | 真实轮廓的地形、地面、建筑；阴影；0.3 起有船，0.4 起有树，0.6 起有屋顶小件，1.2 起有车 |
| 街区 | 约 1.1 起（`uDetail`） | 按原型画的立面、瓦垄、门、红柱 |
| 小景 | 5 起 | 行人 |

全景和城区之间没有过渡，切换的一瞬会跳一下（D024）。

## 各类东西的画法

- **地形**：按坡向加明暗（朝光的一面亮，背光的一面暗一档），陡处露出岩石色，噪声是一块块 80 米的斑驳加颗粒。
- **地面**：水有横带和少量亮纹（远处 1%，近处一成），西湖、运河、池塘是三种青绿，只有钱塘江是土黄色（D053）——不过江面的多边形在 OSM 里没有名字，这条规则对它不生效，目前画面上的江是运河的青绿（`REVIEW-QUEUE.md` 32）；路是安静的颗粒面；草地是原版那种一块块的草色加三点像素的颗粒；林下的地面又暗又有斑；农田有 7 米一垄的沟；茶是 1.6 米一垄、顺着地势弯的行；铺装近看有 5 米一道的小缝。
- **建筑**：九个属性（底面高度、楼高、层数、原型、屋顶类型、墙色、屋顶色、种子、标记）存在一张单通道浮点纹理里，一格一个数，着色器必须逐个读（D048）。墙和屋顶各一个颜色，按原型从颜色表里挑；坡屋顶近看有 35 厘米一道的瓦垄；车站的大屋顶有 21 米一道的天窗带，厂房有 12 米一道的小肋；寺庙殿堂的屋顶更高（屋脊最高到 9 米）。
- **树**：树冠是面向画面的圆盘，按原版"粗糙球体"的算法上色（左上亮、右下暗、逐像素加噪、底下有地面反光），边缘近看变毛糙。垂柳的下缘散成柳丝，松是分层的锥，竹是细长带竖纹的一丛，梧桐的树干是斑驳的浅色。风按 8 帧/秒步进，位移取整到整像素。
- **车、船、人**：盒子。车顶前部有一条挡风玻璃；船是深色船身加浅色船舱，西湖游船白色带青顶；人是腿、身子、头三个盒子。

## 季节

见 D031。冬季的雪按表面类别定覆盖率，用抖动和一片片慢噪声破边，不盖水面（覆盖率为 0 的类别一点雪也没有：破边的噪声不能给它加出来，D041）。

## 地标

手工搭的模型（塔、楼阁、石拱桥、桁架桥、体育场）用和普通楼同一个着色器画，所以光、描边、影子都一样；它们的属性和楼的格式相同。模型站在烘焙记下的地面高度上：塔埋进地面两米（山坡上不露缝），桥不埋（桥面两端要接上路面）。给它们让位的普通楼带着"让位"标记（第 32 位），瓦片、全景和太阳视角的阴影贴图里都不画；塔让位的是一个圆，桥让位的是沿桥长的一条走廊（D052）。

取景（`ui.js` 的 `place`）：相机的中心不放在地标脚下，而是朝着画面下方退一段，退的距离等于"一半高度在 30° 俯角下占掉的地面"，这样地标的一半高度落在画面正中；地标在山顶上也成立，因为高度从烘焙记下的地面算起。点过名字之后拖动是绕着它转（D049）。

## 按名字找到的东西

搜索选中的东西画在地图上面单独一层画布里（`app/src/render/mark.js`），和地图是同一个像素格、同样就近放大。它不进渲染管线，只是一层标注：永远压在楼和树的上面，不投影，不接影。

- **路、江、铁路**：走线是墨色（页面的 `--ink`）的虚线，7 个像素一段、隔 5 个像素；外面一圈纸白的边（八成不透明），所以在任何底色上都读得出来。走线是烘焙时存下的（`data/baked/<城市>/names.bin`），和地图画的是同一份 OSM 几何。
- **楼和地点**：半径 3 个像素的一圈墨色，外面一圈纸白，中间空着，底下的东西看得见。
- **不跨过缺口**：同一条路中间没标名字的那一段不连直线；江只画岸，不画分水的切缝。索引里在缺口处存一个没有位置的点，页面遇到它就断开。
- **虚线的相位跟着世界走**：沿着走线累加的是屏幕上的像素数，但从走线的起点算起，所以拖动地图时虚线相对路不滑动；放大缩小时虚线的一段始终是 7 个像素。

## 悬浮岛

范围是经纬度矩形，投影后是转了约 1.4 度的四边形（`index.json` 的 `island`）。四角 7 公里圆角，边缘 1.5 公里宽的溶解带：向外最多伸 600 米，向里最多咬进 2 公里，最外 11% 的带按抖动散成点化进白色（D018）。地面、建筑、路、树用同一个判定，一起溶解。
